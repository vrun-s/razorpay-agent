## Project in one line

An AI agent that manages Razorpay revenue-recovery cases (failed payments, halted subscriptions) as persistent, multi-step sequences — not one-shot decisions — executing through real Razorpay APIs under a Policy Engine, measured against baselines. Solo build, full-time, 15-day window (started 2026-08-21).
